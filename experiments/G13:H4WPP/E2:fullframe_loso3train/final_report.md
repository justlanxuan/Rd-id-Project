# G13 E2：H4W++ 全帧推理 Custom 三训练 session 四折结果

## 结论

移除稀疏推理后，H4W++ 每个原始视频帧都运行一次，其他协议与 G13 E1 完全一致。
FrameAcc 宏平均为 `73.79%`，加权总体为 `716/982 = 72.91%`，低于 E1 稀疏推理的
`80.89% / 80.24%`。因此，在当前协议下，E1 的高分不能只解释为 3-D skeleton
质量；每 16 帧推理一次并以前向填充形成的时序输入对性能有明显贡献。

这不是“全帧推理一定更差”的普遍结论：E2 仍高于二分类随机基线 `50%`，且不同
session 的变化不一致。它说明需要把骨架表征质量和推理密度作为两个独立因素继续
消融，而不能把 E1 的 `80.89%` 全部归因于 H4W++ 3-D skeleton。

## 解释边界

E2 与 E1 使用相同的 H4W++ 权重、IMU 对齐、窗口 `24/16`、模型、训练轮数和随机种子，
唯一实验变量是 H4W++ `frame_stride`（16 对 1）。全帧 skeleton 仍可能包含模型自身的
检测误差；因此本结果用于归因稀疏推理效应，不等价于理想的逐帧 ground-truth skeleton
对照。
